## Patterns
- When acceptance criteria reference paths (e.g. `docker/entrypoint.sh`), verify the path exists in the target repo before planning — a quick `Glob` check rules out misrouted issues in seconds.
- Test-only providers (e.g. `renderWithProviders` injecting `NextIntlClientProvider`) mask missing production providers; always grep for the provider in `app/` layout files, not just test setup.

## Anti-Patterns
- Marking an issue "success" when the fix target doesn't exist in the repo — should be flagged as `not-applicable` / misrouted rather than success.
- Adding `React.createContext` to a `packages/ui` component without `'use client'` — breaks RSC builds silently until production `next build`.
