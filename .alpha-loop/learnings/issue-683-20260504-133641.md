## Patterns
- Workspace tsconfig packages need explicit `lib: ["es2022", "dom"]` when source uses Web APIs (fetch, Response, AbortController) — match @repo/analytics and @repo/storage.
- Repo-wide `pnpm typecheck` can mask per-package type errors when a package lacks its own typecheck script; verify with `tsc --noEmit` in the package directory.

## Anti-Patterns
- Trusting top-level `pnpm typecheck` as proof a new package is self-contained — packages without their own typecheck script get a free pass.
- Failing to verify proxy/host tests still pass when modifying shared packages consumed by apps/web; even unrelated failures block the run.
