## Patterns
- For one-off audit scripts: prefer multi-roundtrip Supabase queries over installing SECURITY DEFINER RPC helpers (no schema change, no cleanup debt)
- When literal AC conflicts with new evidence (e.g., dev-vs-prod data divergence), document the override in commit + report + follow-up issue rather than mechanically completing the AC

## Anti-Patterns
- Asserting on partial label text (`getByText("Weekly")`) when the rendered label is fuller ("Weekly Summaries") — use exact strings or regex anchored to the actual rendered text
- Importing from a transitively-installed package via a `node_modules/...` relative path; even for throwaway scripts, declare the dep on the script's package or use a workspace re-export
- Marking a session complete while `turbo run test` reports failures (test_fix_retries=0 indicates the failure was not surfaced for repair)
