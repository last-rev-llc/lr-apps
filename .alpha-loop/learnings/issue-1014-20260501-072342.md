## Patterns
- When acceptance criteria reference paths absent from the repo, verify against `CLAUDE.md` scope before attempting implementation

## Anti-Patterns
- Do not attempt to scaffold non-existent infrastructure (Express server, React SPA) into a monorepo that explicitly forbids it
- Do not retry within the same repo when the root cause is orchestration-level routing
- Do not commit transient review artifacts (`review-batch.json`) to the working tree
