## Patterns
- After subdomain proxy rewrites, `revalidatePath` must use the filesystem route (`/apps/<slug>`), not the public URL — mirror the convention in `command-center/cc-flags/lib/actions.ts`.
- Smoke tests for promoted standalone apps should assert on the registry-driven header/subtitle copy plus both empty and populated list states to catch regressions in the shell.

## Anti-Patterns
- Calling `revalidatePath('/')` on a subdomain-routed app — silently no-ops the cache invalidation for the actual route group.
- Asserting only on populated-list rendering; missing empty-state coverage hides null/undefined regressions in the count subtitle.
