## What Failed

## Patterns
- When promoting an app to a standalone subdomain, sweep both the module registry (`page.test.tsx`, `layout.tsx`) AND delete the now-orphaned tests under the old route in the same change.
- For "load into editor" flows, pass the preloaded entity as an `InitialMeme` prop seeded from `listMyMemes()` lookup in the server page — keeps client editor stateful logic unchanged.

## Anti-Patterns
- Shipping a navigation link (`/apps/meme-generator?meme=<id>`) without verifying the destination page consumes the searchParam — query strings without consumers are silent AC failures.
- Relying on test count alone as completeness signal: all tests passed before the review fix, but a critical AC was still unmet.
