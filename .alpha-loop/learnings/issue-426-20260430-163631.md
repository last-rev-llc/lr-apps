## Patterns
- Gate live E2E assertions on a `credentialsPresent()` helper + `test.skip()` so the suite stays green in environments without secrets while still running statically.
- Pair `seedPermission` / `deletePermission` calls inside try/finally per test, with a top-level `afterAll` cleanup as a safety net, to keep `app_permissions` rows in pre-test state across reruns.
- Match unauth redirects with a regex covering both in-app `/login` and Auth0's universal-login domain to avoid flakes when the redirect chain hops domains.

## Anti-Patterns
- Don't rely on exact text matches for headings/tabs that include emoji prefixes — target the role + level or a regex against the literal label.
- Don't enforce the AC's literal beforeAll/afterAll wording when the test matrix needs differing seed states per case; document the deviation instead.
- Don't claim live verification when secrets are absent — explicitly state which AC items were statically vs. runtime verified.
