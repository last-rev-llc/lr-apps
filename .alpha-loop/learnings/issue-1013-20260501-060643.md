## Patterns
- When acceptance criteria reference paths absent from the repo, verify repo identity (CLAUDE.md, package.json, top-level dirs) before attempting fabrication — emit a `fixableInThisRepo: false` verdict with operator action.
- Include `verification.fileSearches` and `repoIdentity` fields in the gate JSON so the orchestrator can detect repo mismatches without re-running the agent.

## Anti-Patterns
- Do not fabricate `docker/`, `dashboard/`, or other foreign directory trees in lr-apps to "satisfy" acceptance criteria — CLAUDE.md forbids new top-level trees and creates dead code.
- Do not retry the same misrouted issue in a loop; surface the root cause as an operational/orchestration error and stop.
