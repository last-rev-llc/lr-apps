## Patterns
- Tier-gate additions are mechanical: append a `FEATURE_LABELS` entry with `requiredTier` and `label`; `hasFeatureAccess` picks them up automatically.
- New env vars consumed by server code must be added to `turbo.json` globalEnv AND `.env.example` — easy to miss when the var is read in a sibling package, not the app reading it.

## Anti-Patterns
- Declaring success without running the full `pnpm test` and reading the failure summary — the proxy integration failures were visible in the test output but not addressed.
- Bundling unrelated work (PGSODIUM_KEY_ID env registration, ai-eval tests, .env.example changes) into a tier-config-only issue blurs scope and complicates review.
