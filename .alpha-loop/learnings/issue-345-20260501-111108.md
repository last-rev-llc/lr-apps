## Patterns
- When promoting/removing an app slug from a registry-driven host, update three sites in one commit: the registry/module list, the route (delete or redirect), and the test fixture array that mirrors the registry.
- Replace deleted in-app pages with `redirect()` from `next/navigation` rather than 404s when the slug may still be linked from external bookmarks/menus — preserves user flow during cutover.

## Anti-Patterns
- Leaving stale `(supabase as any)` casts in adjacent files when touching a query module — repo-wide pattern, but each new instance compounds the lint-warning debt.
