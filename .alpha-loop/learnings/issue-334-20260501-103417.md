## Patterns
- Mock Supabase query builder by returning a chainable object whose terminal methods (`.single()`, thenable on `delete().eq()`) resolve `{ data, error }` — lets server actions be tested without a live DB.
- Mirror existing app patterns (cringe-rizzler, cc-flags) for new server-action files: `"use server"` header, zod validate → db call → `revalidatePath` → return row, all inside `withSpan`.

## Anti-Patterns
- Leaving a routed `page.tsx` as a placeholder `<h1>` while shipping downstream components (CrmApp, queries, enrich route) makes the entire feature unreachable — batch issues should verify the page wires the components.
- Stub components returning `null` (contact-detail.tsx) silently break ACs that depend on UI behavior; tests asserting only "placeholder renders" mask this.
