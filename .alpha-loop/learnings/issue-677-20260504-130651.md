## Patterns
- Stable-name pgsodium keys (`pgsodium.create_key(name => '...')`) make seed scripts idempotent without storing key material outside the DB.
- Required env vars need parallel updates across every CI workflow that boots the dev server (`a11y-audit.yml`, `mobile-audit.yml`, `ci.yml` e2e job) — not just `.env.example`.
- Document rotation procedure alongside the first migration that introduces an encrypted column (`docs/ops/chatflow-eval-rotation.md`) before someone needs it.

## Anti-Patterns
- Declaring success without re-running the failing test suite — `test_fix_retries: 0` on a run with 6 failing tests means the agent never attempted a fix loop.
- Making an env var "required" via zod without auditing every code path that calls `env()` at boot (instrumentation hooks, dev server startup, CI workflows).
