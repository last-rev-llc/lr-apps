## Patterns
- **Frozen system time for date-window UI tests**: when component logic filters by "Last 7/30 days" against hardcoded fixture dates, freeze the clock with `vi.useFakeTimers({ shouldAdvanceTime: true })` + `vi.setSystemTime(...)` and restore in `afterAll`
- **Triage env-caveat pattern**: when a read-only audit runs against dev (not prod), explicitly downgrade confidence on `abandoned`/`stalled` buckets in the report itself so downstream actions inherit the caveat
- **Multi-roundtrip over RPC for one-off audits**: prefer 4 supabase-js round-trips per table over installing a `SECURITY DEFINER exec_sql` helper destined for deletion — risk/reward favors the simpler path

## Anti-Patterns
- Acting on `abandoned` bucket without prod evidence — empty-in-dev is the *expected* state for viewers whose pipelines write to prod; deprecation PRs require prod re-triage
- Adding migrations for tables a feature queries from without verifying the migration exists (caught in review for `leads` table — would have been a runtime break)
