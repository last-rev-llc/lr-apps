## Patterns
- For outbound HTTP clients with secrets: redact in two layers — regex for the protocol pattern (`Bearer xxx`) AND literal substring replace of the actual token value, since servers may echo the token verbatim
- Testing abort propagation: pre-abort the signal and call the function — assert it rejects without ever invoking fetch

## Anti-Patterns
- Treating a turbo pipeline failure as the issue's failure when failing tests are in an unrelated package and pre-exist on main — the harness should scope test gates to the package under change
