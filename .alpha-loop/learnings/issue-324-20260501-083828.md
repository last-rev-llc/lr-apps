## Patterns
- Mocking Supabase at the action boundary (rather than via a full RLS harness) sufficed for cross-user "fails-closed" assertions when the queries scope by `user_id` — simpler than the milestone-014 harness suggested in the issue.
- Structured warn-level logger assertions (e.g., `meme-generator.saveMeme quota exceeded` with `tier`/`current`/`limit` fields) double as both observability and test signals for boundary conditions.
- Hour-windowed rate-limit testing by looping 30 successful calls then asserting the 31st throws without invoking the model is a clean way to verify both the limit and the no-side-effect contract.

## Anti-Patterns
- Issue scope was inflated by unrelated meme-generator promotion work (deleted command-center subroute tests, layout/page module list edits) — should have been a separate PR; mixing scope makes review harder and risks regressions outside the test-coverage goal.
- Inline quota-exceeded `Dialog` diverges from the shared `<UpgradePrompt>` component used elsewhere — flagged as info during review but left unfixed; future tests assert the divergent path, locking in the inconsistency.
