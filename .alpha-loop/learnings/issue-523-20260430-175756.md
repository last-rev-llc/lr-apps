## Patterns
- Freeze system time with `vi.setSystemTime(new Date("YYYY-MM-DD..."))` + `afterAll(() => vi.useRealTimers())` when tests assert against fixtures with hardcoded dates relative to "today."
- Document target env + caveats explicitly in triage reports when running against dev (vs prod read-replica) — empty-in-dev is not evidence of abandonment.
- Separate target/query-path decision doc from the triage report itself, so prerequisite decisions are auditable independent of run output.

## Anti-Patterns
- Don't treat a `stalled`/`abandoned` bucket from a dev-env run as actionable for deprecation PRs — prod evidence required.
- Don't install one-off `SECURITY DEFINER exec_sql` helpers just to delete them; multi-roundtrip via supabase-js is acceptable for one-off audit scripts.
