## Patterns
- When a workspace package has no `typecheck` script of its own, repo-wide `pnpm typecheck` can pass while the package's tsconfig is silently broken — verify by running `tsc --noEmit` directly inside the package.
- Token-redaction errors should be tested with the input token literally echoed in the upstream response body to prove both the regex and the literal-string redaction paths work.

## Anti-Patterns
- Treating "tests pass at the repo level" as proof of package-level type correctness when the package lacks its own typecheck entry point.
- Letting unrelated pre-existing test failures (proxy.integration auth-hub rewrites) block a run without flagging them as out-of-scope vs. caused-by-this-change.
