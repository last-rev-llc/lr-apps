## Patterns
- For pgsodium-encrypted columns: route encrypt/decrypt through Supabase RPCs (ai_eval_encrypt_target_token / ai_eval_decrypt_target_token) rather than inlining `crypto_aead_det_*` SQL — keeps key_id server-side and lets the typed projection omit `api_token_encrypted` cleanly.
- Pair the `import "server-only"` boundary with a CI grep test (no-token-logging.test.ts) that asserts the source file contains no `apiToken` / `api_token` / `Authorization` log calls — defense-in-depth against accidental leaks during future edits.

## Anti-Patterns
- Treating a whole-monorepo `turbo run test` failure as a signal about the current package: pre-existing failures in unrelated packages mask the real signal. Need per-package gating or an allowlist of known-failing suites.
