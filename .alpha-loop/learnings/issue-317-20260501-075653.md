## Patterns
- Pull AI provider invocation into a small `lib/ai-*.ts` module so the server action can be tested without re-mocking `generateObject`; mirrors the existing `ideas/lib/ai-plan` and `cringe-rizzler` deterministic-stub pattern.
- Build dynamic zod shapes from template metadata (`z.object({ [zoneId]: z.string().max(80) })`) rather than hand-writing per-template schemas — keeps schema and template config as a single source of truth.
- Register new AI keys in both `turbo.json` `globalEnv` and `apps/web/lib/env.ts` in the same change to keep typed access and turbo cache invalidation aligned.

## Anti-Patterns
- Don't mock the entire `@ai-sdk/anthropic` surface in action tests — extracting the provider call into a thin lib module and mocking that module is far less brittle.
- Avoid putting the deterministic-stub branch inside the action itself; keep it in the lib module so the action stays focused on auth/rate-limit/schema and tests for those concerns don't have to touch the stub path.
