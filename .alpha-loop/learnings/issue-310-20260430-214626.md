## Patterns
- Path-prefixed RLS via `storage.foldername(name)[1] = auth.uid()::text` is the canonical pattern for per-user blob isolation in Supabase Storage.
- Public buckets with service-role-only writes: omit insert/update/delete policies entirely rather than writing restrictive ones — RLS denies by default.
- When relocating an app's route, sweep three places: the hub page tile list, the sidebar layout entries, and the page test's EXPECTED_MODULES (with a paired negative assertion).

## Anti-Patterns
- Don't edit a merged migration to add buckets — append a new migration with paired down file (enforced by `check-migration-pairs.ts`).
- Don't write public-bucket policies for writes when the intent is service-role-only; the absence of a policy is the policy.
