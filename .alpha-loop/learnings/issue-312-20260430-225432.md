## Patterns
- **Structural typing for canvas tests**: define a `CanvasContextLike` interface mirroring only the methods/properties the renderer touches, then build a fake-context factory that records calls into an array. Avoids `jsdom` canvas polyfill and gives precise per-call assertions.
- **Zone-driven rendering with legacy compatibility**: synthesize legacy `top`/`bottom` zones server-side in seed data so a single renderer handles both color-scheme and image templates — no branching at the call site.
- **Cache-invalidation contract in comments → must be enforced**: when an action's docstring says "seed script must call cacheDel(...)", grep the seed script in review; comments are not enforcement.

## Anti-Patterns
- Documenting a cache-invalidation requirement in a server action comment without wiring it into the seed script that's expected to honor it. Worked here only because review caught it.
- Passing storage paths (`'61579.jpg'`) where URLs are expected. If `imagePath` is a path, the type/name should make that clear (`imageStoragePath`) and resolution to a public URL should happen at one well-defined boundary.
