## Patterns
- When acceptance criteria reference paths that don't exist in the repo, verify repo identity against `CLAUDE.md` / directory structure before attempting fixes

## Anti-Patterns
- Do not retry code fixes when the root cause is misrouting — retries cannot create files that belong in another repository
- Do not leave `review-batch.json` artifacts on the branch between runs; they create noise in diffs and confuse downstream review
