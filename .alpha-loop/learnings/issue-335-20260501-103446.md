## Patterns
- Schema-first AI generation: define the Zod schema as the contract (`InsightsSchema`), then `generateObject({ schema, ... })` lets the SDK enforce the shape — caller gets typed output without manual JSON parsing.
- Span attribute timing: when a span ID is only known post-validation, opening the span early with `{}` and calling `span.setAttribute(...)` after parsing is functionally equivalent to passing it as initial attrs.

## Anti-Patterns
- Accepting "type union with string fallback" (`'high'|'medium'|'low'|string|null`) on a field the schema strictly constrains — works because schema is a subset, but invites drift; tighten the type to match the schema unless legacy rows truly need the escape hatch.
- Letting `object as ContactInsights` casts hide schema/type divergence rather than aligning the two definitions.
