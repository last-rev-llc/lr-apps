## What Failed

- page.test.tsx was written against the placeholder, so it would have masked the dead-code bug if review hadn't required the rewire.

## Patterns
- When adding a schemas/types module, mirror the existing type shape from lib/types.ts and add a focused __tests__/schemas.test.ts that exercises each enum/length boundary.
- Reviewer-as-integrator: have the review pass verify the new module is actually mounted in the routed page, not just that the file exists and tests pass.

## Anti-Patterns
- Shipping a "scaffolding" page.tsx and component stub alongside real lib code — passing tests on isolated modules can hide that the feature is unreachable end-to-end.
- Writing page tests that only assert on placeholder text; they lock in the placeholder instead of catching missing wiring.
