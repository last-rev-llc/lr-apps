## What Failed
- Initial implementation of the library "Load into editor" link constructed `?meme=<id>` URLs but neither `page.tsx` nor `MemeEditor` consumed `searchParams`, so AC #322 (preload editor state) was silently unmet until review.

## Patterns
- When adding a deep-link URL param, write the consumer (page reads searchParams → passes prop → component seeds initial state) in the same change as the producer (link builder), and add a test that asserts the seeded state.
- Tier-aware UpgradePrompt copy is cleanly isolated in a small pure helper (`upgrade-copy.ts`) with its own table-driven test — easy to extend for new tiers.

## Anti-Patterns
- Generating a query-string URL without verifying the receiving page actually reads it. A passing render test on the link is not evidence that the round-trip works.
- Relying on AC checklists alone without an integration test that exercises the full producer→consumer flow for navigation params.
