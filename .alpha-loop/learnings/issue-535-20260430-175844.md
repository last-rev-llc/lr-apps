## Patterns
- When tests reference hardcoded dates in date-window filters (Last 7/30 days), freeze the clock at module scope with `vi.useFakeTimers({ shouldAdvanceTime: true })` + `vi.setSystemTime(...)` and restore in `afterAll` to prevent time-drift flakes.
- For one-off audit/triage scripts, document the env target and query-path decision in a separate decision doc before authoring the report — keeps the report focused on findings and the rationale auditable.
- Dev-env audits must explicitly downgrade confidence on `abandoned`/`stalled` buckets — empty-in-dev is the expected state for viewer apps whose pipelines write to prod.

## Anti-Patterns
- Don't ship features that query a Supabase table without verifying a migration exists for that table — registry/UI wiring without schema is a runtime trap that won't fail typecheck or unit tests.
- Don't keep one-off CLI audit scripts past their deletion checkpoint; they invite re-runs against wrong envs and drifted schemas.
