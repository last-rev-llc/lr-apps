## Patterns
- Network-level mocking via Playwright `page.route()` for AI endpoints is more robust than msw for E2E and lets you assert no real API was hit.
- For free-tier users, the "AI caption" step in a flow can be validated by asserting the upgrade prompt opens — exercises the gate without needing a pro fixture.
- When promoting a sub-app to a standalone subdomain, sweep command-center registry + layout + page tests in the same change to keep the module list canonical.

## Anti-Patterns
- Don't hardcode the exact spec path from the issue when a subdirectory (`tests/e2e/meme-generator/studio-flow.spec.ts`) reads better; Playwright glob discovery makes the path cosmetic.
- Don't insist on the shared `<UpgradePrompt>` component for every quota path when the inline Dialog already renders the same `quotaUpgradeCopyForTier()` copy — duplication of behavior, not of components, is what the AC actually requires.
