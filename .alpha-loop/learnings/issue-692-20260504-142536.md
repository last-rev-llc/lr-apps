## Patterns
- `describe.skipIf(!process.env.SUPABASE_TEST_URL)` is the right way to author integration tests that ride alongside unit tests without breaking hermetic local runs.
- Seeding test users via `admin.auth.admin.createUser` with deterministic UUIDs + `afterEach` table cleanup keeps cross-test state predictable.
- Documenting rotation/key-rollover behavior inline (rather than only in an external doc) makes the contract visible at the assertion site.

## Anti-Patterns
- Landing a test file whose `import` target lives on a sibling branch creates a guaranteed type/lint failure unless the entire batch merges atomically — the failure mode is invisible until CI runs.
- Referencing forward-looking documentation paths (`docs/ops/chatflow-eval-rotation.md`) that don't exist yet leaves dangling pointers.
- Pre-existing unrelated test failures (proxy auth-hub rewrites) were not triaged before this run, masking the actual ai-eval signal.
