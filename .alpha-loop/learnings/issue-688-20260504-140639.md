## Patterns
- When a package reads `process.env.X` directly, register `X` in `turbo.json` globalEnv AND document in `.env.example` in the same PR — pre-commit lint won't catch the gap
- For "must not log secret" acceptance, write a grep-based static test asserting the source file contains no occurrences of the sensitive token names; runs in CI cheaply

## Anti-Patterns
- Declaring a feature complete when sibling tests in the monorepo are red — `turbo run test` is repo-wide and a failing proxy test fails the whole run regardless of scope
- Adding code that depends on Supabase RPCs/tables before the migration lands; even with mocks passing, the feature can't be exercised end-to-end
