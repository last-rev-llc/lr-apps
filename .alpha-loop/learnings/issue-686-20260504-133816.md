## Patterns
- When adding a new package or file using browser/Node globals (Response, fetch, AbortController, setTimeout, TextEncoder), ensure the package tsconfig includes `lib: ["es2022", "dom"]` — repo-wide typecheck can mask gaps when the package lacks its own typecheck script.
- Port verbatim from source repo first, then layer additional helpers (formatCSV, formatEvalRunCSV) on top — keeps the well-tested core untouched.

## Anti-Patterns
- Relying on `pnpm typecheck` at the repo root to validate per-package TypeScript correctness when packages don't define their own typecheck script.
- Inheriting only `lib: ["es2022"]` in shared base tsconfig when packages use DOM-adjacent globals.
