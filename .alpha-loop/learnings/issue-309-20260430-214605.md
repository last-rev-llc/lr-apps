## Patterns
- When relocating an app out of `command-center`, sweep three places in lockstep: hub page tile, sidebar layout entry, and `EXPECTED_MODULES` in the page test (with a matching negative-assertion test).
- Per-user RLS migrations should pair `auth.uid() = user_id` policies for all four CRUD verbs with a `before update` trigger and a `(user_id, "createdAt" desc)` index.
- Down migrations drop in reverse order: trigger → function → policies → index → table.

## Anti-Patterns
- Deleting a route without grepping for inbound links in sibling hub/sidebar/test files leaves 404s — the `ideas` cleanup precedent should have been applied immediately, not caught in review.
- Leaving stale module names in `EXPECTED_MODULES` arrays without a paired negative assertion masks regressions when the corresponding tile is removed.
