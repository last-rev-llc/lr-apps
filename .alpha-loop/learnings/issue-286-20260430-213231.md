## Patterns
- For "do not page" requirements, assert the negative on the logger mock directly (`expect(logErrorMock).not.toHaveBeenCalled()`) — more precise than asserting alert table state.
- When a cron fans out side effects from results, filter to the success-only subset at the top of the fanout function and add a comment tying the filter to the issue number; makes the non-paging contract self-documenting.
- Pair "failure preserves prior state" behavior with a two-call test that asserts the upsert payload omits the preserved columns rather than asserting their values.

## Anti-Patterns
- Don't ship UI components (`SslBadge`) and scoring helpers (`computeHealthScore`) without a consuming page in the same batch — leaves dead code that passes review only because unit tests exist.
- Don't claim AC coverage via unit tests alone when the AC implies a rendered UI state ("badge renders neutral 'data unavailable'") — flag the wiring gap explicitly.
