## Patterns
- `revalidatePath` always takes Next.js filesystem routes (`/apps/<slug>`), never the proxied user-facing path — convention in `command-center/cc-flags/lib/actions.ts`.
- Shared form component takes `onSubmit: (input) => Promise<void>` so callers wire up their own server actions (create vs edit) — keeps the form a pure controlled component.
- Mock Supabase chain pattern (insert/update/delete with `.eq().select().single()` thenable) is reusable for CRM-style action tests.

## Anti-Patterns
- Using user-facing URLs (`/`, `/contacts`) with `revalidatePath` in subdomain-rewritten apps — silently breaks list refresh after mutations because the framework looks up a different route key.
- Importing Radix primitives directly in app components when `@repo/ui` already wraps them — bypasses theme-token enforcement.
