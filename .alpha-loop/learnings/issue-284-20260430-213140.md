## Patterns
- Pair every new feature-flag entry with a `tier-config.test.ts` case in the same commit; keeps the registry and its contract test in lockstep.
- For non-paging failure paths (e.g. SSL handshake errors), assert on the log level (`logWarnMock` vs `logErrorMock`) in tests — encodes the on-call contract directly.
- Partial-column upsert for transient failures preserves prior good values (`sslExpiry`/`sslIssuer`); test by asserting the upsert payload does NOT contain those keys.

## Anti-Patterns
- Shipping helpers/components (SslBadge, `computeHealthScore`) that are unit-tested but not wired into any production page — leaves dead code that looks "done" but isn't user-visible. Either wire it up or defer the implementation until the consuming page exists.
- E2E specs that comment out or label assertions as "(Stub)" without an explicit `test.skip()` — silently lets unverified AC slip through review.
