## Patterns
- When introducing env vars consumed by package code (e.g. `process.env.PGSODIUM_KEY_ID`), register them in `turbo.json` globalEnv AND document in `.env.example` in the same commit — non-negotiable #6 in CLAUDE.md.
- Write-only sensitive form fields: never derive `defaultValue`/`value` from server data; show a separate read-only "Token: ••• (leave blank to keep)" indicator instead.

## Anti-Patterns
- Landing changes when unrelated tests on `main` are red — the worktree-scoped agent had no signal that proxy tests were already broken pre-change. Failure mode: agent's own work passes but `turbo run test` fails on a sibling package.
- Referencing Supabase RPCs/tables that don't yet exist as migrations (ai_eval_encrypt_target_token, chatflow_targets, etc.) — works under FakeSupabase mocks but is a runtime trap deferred to a follow-up issue.
