## Patterns
- When relocating a route, sweep `command-center` hub page, sidebar layout, AND the page test's `EXPECTED_MODULES` list together — the `ideas` removal is the canonical precedent to mirror.
- Pair every new migration with its `.down.sql` in the same commit; the lint gate enforces this and the down should drop policy → index → table in reverse order.
- Seed data that backs runtime behavior (e.g. renderer color schemes) belongs in the up migration, not a separate seed script, so a fresh DB is immediately functional.

## Anti-Patterns
- Deleting a route group without grepping for hard-coded links in sibling hub/sidebar files leaves 404 tiles (caught here, originated in #307).
- Updating `EXPECTED_MODULES` test fixtures without adding the symmetric "does not render" assertion lets future regressions slip back in silently.
