- Caught a tsconfig drift in `packages/ai-eval` (missing `dom` lib) and fixed by aligning with sibling packages (`@repo/analytics`, `@repo/storage`).

## What Failed
- `@repo/web` test suite failed: 6 proxy integration tests in `apps/web/__tests__/proxy.integration.test.ts` for `auth.apps.lastrev.com` host parsing returned `null` for `x-middleware-rewrite` instead of a rewrite URL — pre-existing failures unrelated to queue.ts work but blocked the run.

## Patterns
- When adding a new package under `packages/`, copy `tsconfig.json` `compilerOptions.lib` from the closest sibling (e.g., `@repo/analytics`) to avoid lib drift, especially for packages using `fetch`, `Response`, `AbortController`, or DOM types.
- Rolling-concurrency engines: track in-flight count + a "next index" pointer; resolve a per-row `AbortController` from union of outer signal + `shouldCancel` poll, and always run `onComplete` in a `finally`.

## Anti-Patterns
- Relying on apps/web's inherited `dom` lib to mask missing lib entries in workspace packages — the package must be self-typecheckable.
- Declaring "complete" without running the full `pnpm test` against the worktree; the proxy integration failures (unrelated) still gate the run.
