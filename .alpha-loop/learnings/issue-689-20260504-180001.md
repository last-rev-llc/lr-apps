## Patterns
- Server-only Supabase wrapper: delegate transactional + atomic operations to Postgres RPCs (create_chatflow_run, bump_chatflow_run_counters) rather than client-side multi-statement sequences.
- Terminal-state guards belong in the SQL `WHERE status IN ('queued','running')` clause so cancel is naturally idempotent.
- Schema-dependent packages can ship and pass tests before migrations land, as long as runtime callers are gated separately.

## Anti-Patterns
- Treating the whole monorepo's `turbo run test` exit code as a per-issue signal — pre-existing failures in unrelated packages (apps/web proxy tests) mask actual per-package success.
- Don't attempt to "fix" the 6 proxy.integration.test.ts failures from this issue's worktree; they live on main and modifying proxy.ts here would be scope creep.
