## Patterns
- When adding env vars consumed at runtime, always register them in `turbo.json` globalEnv AND document in `.env.example` together — single atomic change.
- For pure utility modules like URL builders, `encodeURIComponent` on the entire `${tag}_${uid}` composite (not piece-wise) is the correct way to satisfy "encode reserved chars in tag" while keeping uid encoded too.

## Anti-Patterns
- Declaring a per-issue run "complete" while `@repo/web#test` fails on unrelated proxy tests — the harness reports failure even though acceptance criteria for #687 were met. Either gate test scope to the affected package or fix the upstream proxy regression first.
- Bundling related-but-separate issue scope (tier-config labels, env var for target-store) into a langfuse-only issue obscures attribution and makes per-issue rollback harder.
