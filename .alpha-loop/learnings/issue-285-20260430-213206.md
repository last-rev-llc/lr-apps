## Patterns
- When fixing an alert/paging bug, add tests that assert log level (warn vs error) AND assert the side effect (no alert insert) — covers both observability and behavior.
- Reference the issue number in test descriptions ("issue #286: ...") to make regression intent traceable when scanning test output later.
- Partial-column upsert pattern: omit fields you don't want to clobber (sslExpiry/sslIssuer) rather than writing null — preserves prior values across consecutive failures.

## Anti-Patterns
- Don't claim AC met when the supporting UI page doesn't exist — flag as INFO/blocked-by-scope rather than silently skipping assertions.
- Don't ship unit-tested helpers (SslBadge, computeHealthScore) without a tracking issue for the wiring step — they become dead code until someone notices.
