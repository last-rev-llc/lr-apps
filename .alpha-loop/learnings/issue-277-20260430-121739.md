## Patterns
- Fire-and-forget server-action → internal API pattern: server action awaits nothing, catches+logs the fetch failure, and returns success regardless. Keeps user-facing latency low while still triggering background work.
- Per-IP rate limiting via `lib/rate-limit.ts` with the request's IP as the key for unauthenticated-but-internal endpoints, rather than per-user.
